Security research

  1. 01 consolebugs A 14-phase web security auditor covering DNS, SSL, headers, port scanning, injection, CORS and technology fingerprinting — then generates a formal HTML audit report you can hand to someone. PowerShell · Recon · Reporting ↗
  2. 02 ThreatLens Shows a system through an attacker's eyes — a hacker-perspective analysis tool for finding exposure before someone else does. Python · Security ↗
  3. 03 Lineage Git provenance and code-similarity engine. Traces every line back to its origin, detects cross-repository code copying, and measures structural similarity between projects. Python · Git · Forensics ↗
  4. 04 websiteinjectiontester Whitehat web scanner that fuzzes URL parameters and analyses HTML forms to detect SQL injection and XSS automatically. Python · SQLi · XSS ↗

AI & LLM infrastructure

  1. 05 PRISM Modular AI research proxy: a 19-layer prompt engine with 8-level escalation, obfuscation, multi-provider routing, a plugin system and its own CLI. TypeScript · Bun · Proxy ↗
  2. 06 BasicLLM OpenAI-compatible gateway using UCB1 bandit routing across 20+ free providers, with circuit breakers, session stickiness and automatic failover when a provider drops. TypeScript · Routing · Resilience ↗
  3. 07 SlimWeights Model compression toolkit that shrinks GGUF weights without losing usable quality. Q2_K through Q8_0 quantisation, on an ordinary laptop rather than a GPU rig. Python · GGUF · Quantisation ↗
  4. 08 Kwen v0.2 Local uncensored model finetuned from Qwen2.5 for technical and coding work, trained with QLoRA and served through Ollama. Python · QLoRA · Ollama ↗

Developer tools

  1. 09 RootClaude A real terminal for any LLM. Open-source coding agent with 6+ model providers, a skills system, and DeepScrape wired in so agents can pull live data. TypeScript · Agent · CLI ↗
  2. 10 deepscrape CLI that turns a website into a command-line interface. Written in Rust, and driven by AI rather than a pile of brittle selectors. Rust · Scraping · CLI ↗
  3. 11 rootfetch Self-hostable research and content-extraction API — a drop-in alternative to the hosted search-and-extraction services. Python · API · Self-hosted ↗
  4. 12 devkit Developer CLI toolkit for the boring half of shipping: smart commit messages, PR descriptions, code review and changelog generation. TypeScript · Git · CLI ↗
  5. 13 kwen-ext Media extractor toolkit — pulls direct video streams, download links and metadata off streaming sites instead of making you inspect the page. Python · CLI · Media ↗

Web products

  1. 14 Kwen Live A web product running in production on Vercel. The largest and most actively developed thing I ship, and the reason the rest of this list exists. TypeScript · Next.js · Vercel Live site ↗ ↗
  2. 15 Kwen Source The open-source repository behind kwen.in. TypeScript · Next.js ↗
  3. 16 feio library A free open-source digital library that aggregates over 7 million classic books from Open Library, Project Gutenberg and the Internet Archive into one searchable place. TypeScript · APIs · Search ↗

About

I work on three things that happen to overlap: security research, AI/LLM infrastructure, and developer tooling. Most projects start because I needed the tool to exist, and then keep going because other people needed it too.

The through-line is making hard things usable without heavy infrastructure. Model compression that runs on a laptop. Web scraping that turns a site into a shell command. Security audits that output a report a human can actually read and hand to someone.

Everything is public and permissively licensed. If something here saves you an evening, the source is one click away.
