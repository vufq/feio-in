Security research

  1. 01 consolebugs↗ A 14-phase PowerShell web security auditor covering DNS, SSL, headers, port scanning, injection, CORS and technology fingerprinting — then generates a formal HTML audit report you can hand to someone. PowerShell · Recon · Reporting PowerShell
  2. 02 githubsecurityaudit↗ PowerShell toolkit that runs 40+ security checks across six categories and writes Markdown reports with severity ratings and remediation steps for each finding. PowerShell · 40+ checks · Markdown reports PowerShell
  3. 03 ThreatLens↗ Shows a system through an attacker's eyes — a hacker-perspective analysis tool for finding exposure before someone else does. Python · Security Python
  4. 04 websiteinjectiontester↗ Whitehat web scanner that fuzzes URL parameters and analyses HTML forms to detect SQL injection and XSS automatically. Python · SQLi · XSS Python · 1 star
  5. 05 Lineage↗ Git provenance and code-similarity engine. Traces every line back to its origin, detects cross-repository code copying, and measures structural similarity between projects. Python · Git · Forensics Python

AI & LLM infrastructure

  1. 06 PRISM↗ Modular AI research proxy: a 19-layer prompt engine with 8-level escalation, obfuscation, multi-provider routing, a plugin system and its own CLI. TypeScript · Bun · Proxy TypeScript · MIT
  2. 07 BasicLLM↗ OpenAI-compatible gateway using UCB1 bandit routing across 20+ free providers, with circuit breakers, session stickiness and automatic failover when a provider drops. TypeScript · Routing · Resilience TypeScript · MIT
  3. 08 SlimWeights↗ Model compression toolkit that shrinks GGUF weights without losing usable quality. Q2_K through Q8_0 quantisation, on an ordinary laptop rather than a GPU rig. Python · GGUF · Quantisation Python
  4. 09 Kwen v0.2↗ Local uncensored model finetuned from Qwen2.5 for technical and coding work, trained with QLoRA and served through Ollama. Python · QLoRA · Ollama Python
  5. 10 jailbroke2n↗ OpenAI-compatible proxy that injects a 19-layer system prompt, applies Parseltongue obfuscation, auto-detects refusals, and retries with six escalation strategies before giving up. TypeScript · Proxy · Prompt research TypeScript · 1 star

About

About

The output is mostly reports, proxies and command-line tools. A 14-phase auditor that ends in an HTML report you can send to someone. A gateway that routes around a dead provider instead of erroring. A scraper that turns a website into a shell command. Model compression that runs on a laptop instead of a GPU rig.

I work on three things that happen to overlap: security research, LLM infrastructure, and developer tooling. They overlap because the same problem keeps showing up in all three — something works, but not in a way you can hand to another person.

The through-line is making hard things usable without heavy infrastructure. Most projects start because I needed the tool to exist, and then keep going because other people needed it too.
