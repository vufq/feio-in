About

I work on three things that happen to overlap: security research, AI/LLM infrastructure, and developer tooling. Most projects start because I needed the tool to exist, and then keep going because other people needed it too.

The through-line is making hard things usable without heavy infrastructure. Model compression that runs on a laptop. Web scraping that turns a site into a shell command. Security audits that output a report a human can actually read and hand to someone.

Everything is public and permissively licensed. If something here saves you an evening, the source is one click away.
